# design/ — 设计稿目录

> 维护方：设计负责人 ｜ 消费方：S1（开发）

## 上传规范

1. 设计稿文件直接放在本目录，命名：`YYYYMMDD-主题-vN.扩展名`
   - 例：`20260910-home-hero-v2.png`、`20260912-mascot-page-设计说明-v1.md`
2. 支持格式：PNG / JPG / PDF / Figma 导出 / Markdown 设计说明
3. **每次上传后在下表登记一行**（S1 以这张表判断哪个是最新稿）：

| 日期 | 文件 | 变更要点 | 优先级 |
|---|---|---|---|
| （示例）2026-09-06 | — | 目录初始化，等待首批设计稿 | — |

4. 大改版建议附一份 Markdown 设计说明：页面结构、色板、字号、交互说明，S1 照此实现。

## 注意

- 本目录是公开仓库的一部分，设计稿一旦上传即公开，请勿放入含客户信息或未公开合作方的素材。
